# Audio Haptics 1.0 — هزاز عبر السماعات الأربع (SM-T505N / LineageOS 24 / Android 17)

وحدة LSPosed تجعل النظام يرى هزازاً حقيقياً، وتشغّله عبر السماعات الأربع (إخراج رباعي بقطبية مضبوطة).

## البناء والتثبيت
1. ارفع كل محتويات المجلد إلى مستودع GitHub (تأكد من `.github/workflows/build.yml`) ← Actions ← `build` ← نزّل الـ APK.
2. ثبّته، ثم LSPosed ← فعّل الوحدة ← النطاق: **System Framework** ← أعد التشغيل.
3. افتح التطبيق (يمنح نفسه صلاحية الحفظ عبر root تلقائياً) ثم اضغط **«ابدأ الضبط التلقائي»** مرة واحدة والجهاز على طاولة ثابتة.

## ما الجديد
- واجهة جديدة مبسطة: زر تشغيل/إيقاف، قوة اللمس، قوة التنبيهات، طابع (هادئ/متوازن/قوي)، وإعدادات متقدمة مطوية.
- **إصلاح تداخل الأيربودز:** مسار الصوت لا يبقى مفتوحاً إلا حين يكون الاهتزاز فعّالاً. يُغلق كلياً عند: الإيقاف، الوضع الصامت، المكالمات، أو توصيل أي جهاز صوت خارجي (بلوتوث/سلكي/USB/HDMI)، ويعود تلقائياً.
- **قطبية السماعات:** قياساتك أثبتت أن السماعتين اليسريين معكوستان بالنسبة لليمنيين؛ الافتراضي الآن يجمع الأربع بدل أن تلغي نصفها. والضبط الذكي يقيسها ويضبط التردد تلقائياً.
- **بلاطة إعدادات سريعة** «اهتزاز السماعات» لتشغيله/إيقافه من لوحة الإشعارات.
- التطبيق يعرض حالة الوحدة (يعمل / صامت / سماعات / مكالمة).

## الإنقاذ إذا حدث خلل
- حماية تلقائية: بعد 3 إقلاعات فاشلة متتالية تعطّل الوحدة نفسها.
- يدوياً: `touch /data/system/audiohaptics.disable` ثم أعد التشغيل، أو عطّل الوحدة من LSPosed، أو الوضع الآمن.
